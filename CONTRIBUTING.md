# Contributing to StopReels

StopReels is developed on the protected `main` branch.

## Contribution workflow

1. Fork the repository.
2. Create a feature branch from `main`.
3. Make focused changes and add or update tests when relevant.
4. Open a Pull Request against `main`.
5. Wait for review and the required checks before merging.

Direct pushes to `main` are disabled. Pull Requests may be reviewed, requested for changes,
or closed by the project maintainer.

By opening a Pull Request, you confirm that you have the right to submit the contribution
and that it can be distributed under the project's applicable licence.
