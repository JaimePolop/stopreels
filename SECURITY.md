# Security policy

## Reporting a vulnerability

Please do not publish credentials, private accessibility-tree data, device
identifiers, or an exploit in a public issue. Contact the maintainer privately
through the security contact configured for the GitHub repository. Include:

- the affected version and Android version;
- the smallest reproducible description;
- the expected and observed behaviour; and
- any safe mitigation or patch you have tested.

StopReels is designed to work locally. It does not request Internet access,
accounts, analytics, screenshots, or a backend. Never attach a keystore,
password, token, or personal Instagram data to an issue or Pull Request.

## Supported versions

Only the latest version on `main` is actively maintained. Security fixes are
reviewed through Pull Requests and released after validation.
